# Правила работы над проектом

Задание, требования, стек и этапы описаны в `README.md`, внешний вид и состав экранов —
в `design/DESIGN.md`. Прочитай оба файла перед любой работой.

## Как работаем

1. Работаем по этапам из README, строго по одному этапу за раз.
2. Перед каждым этапом пиши план без кода: какие файлы создашь или изменишь, какие пакеты
   поставишь и как я проверю результат. Жди моего подтверждения, без него код не пиши.
3. Если есть несколько способов, предлагай варианты от самого простого.
4. Шаги мелкие и проверяемые: написал, запустил, проверил. Сам запускай сборку, линтер,
   тесты и миграции и исправляй ошибки до того, как отдать этап мне на проверку.
5. Меняй только то, что я попросила. Не трогай файлы и код, которые не относятся
   к текущему этапу.
6. После изменений коротко объясни каждый новый фрагмент кода: что он делает и зачем.
7. Не добавляй зависимости и функции сверх README без моего согласия.
8. Перед выполнением команд в терминале говори, что команда делает.
9. Не выполняй без моего согласия команды, которые требуют прав администратора,
   ставят программы в систему или удаляют данные в базе.
10. В конце этапа дай мне короткий список проверки по колонке «Результат и проверка»
    из README: что открыть, что нажать, что должно получиться.

## Git

- Каждый этап делаешь в ветке `etap-N` (например, `etap-1`).
- Коммит делается в конце этапа, после того как я проверила результат и разрешила.
  Затем вливаешь ветку в `main` и отправляешь на GitHub (`git push`).
- Сообщение коммита на русском: «Этап N: краткое описание».
- Миграции Prisma (`apps/api/prisma/migrations/`) коммитим вместе с этапом.
- Файл `.env` никогда не коммитим.

## Окружение

- Windows 10, Node.js 24, Git for Windows, терминал Git Bash.
- PostgreSQL установлен локально как служба Windows, порт 5432; база `flashcards`
  и пользователь `flashcards` уже созданы.
- Проект лежит в `C:\rufus\flashcards`. Пути только латиницей и без пробелов.
- `npm run dev` запускает сервер (`http://localhost:3000`) и интерфейс (`http://localhost:5173`);
  открывать в браузере адрес интерфейса.
- Настройки подключения к базе и секрет сессий — в `apps/api/.env`.
- Интерфейс и сообщения пользователю на русском.
