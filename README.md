# Карточки — флеш-карточки для английского

Веб-приложение для изучения английских слов: пользователь регистрируется, составляет свои колоды карточек «английский ↔ русский» и листает их, переворачивая карточку, чтобы увидеть перевод. Аналог Quizlet, урезанный до флеш-карточек.

Сейчас работает локально; стек выбран так, чтобы позже приложение можно было разместить на сервере и открывать с любого устройства.

## 1. Границы

**В рамках:** колоды и карточки, просмотр с переворотом, регистрация и вход, у каждого пользователя свои данные.

**Вне рамок (пока):** режимы теста и заучивания, интервальные повторения, статистика, другие языки, картинки и озвучка, подтверждение email и сброс пароля (нужен почтовый сервис), вход через Google/VK, ограничение попыток входа, размещение в интернете.

**Допущения:** на карточке только слово/фраза и перевод (без примера и транскрипции); без отметки «знаю / не знаю».

## 2. Требования

### Авторизация

| № | Требование |
|---|---|
| A1 | Регистрация по email и паролю (пароль не короче 8 символов, email уникален). |
| A2 | Вход и выход. После перезагрузки страницы пользователь остаётся залогиненным. |
| A3 | Без входа доступны только экраны входа и регистрации; остальное перекидывает на вход. |
| A4 | Пользователь видит и меняет только свои колоды и карточки; чужую колоду нельзя открыть даже по прямому адресу (ответ 404). |
| A5 | Пароль хранится только как хеш; секреты лежат в `.env`, в git попадает только `.env.example`. |

### Колоды

| № | Требование |
|---|---|
| F1 | Пользователь создаёт колоду с названием. |
| F2 | Видит список своих колод и количество карточек в каждой. |
| F3 | Может переименовать и удалить колоду. Перед удалением — подтверждение. |

### Карточки

| № | Требование |
|---|---|
| F4 | В колоду добавляется карточка: английское слово или фраза и перевод на русский. |
| F5 | Карточку можно отредактировать и удалить. |
| F6 | Внутри колоды виден список всех её карточек. |

### Просмотр

| № | Требование |
|---|---|
| F7 | Показывается одна сторона карточки; по клику или клавише «Пробел» карточка переворачивается. |
| F8 | Переход к следующей и предыдущей карточке: кнопки и клавиши ← →. |
| F9 | Счётчик положения, например «5 / 20». |
| F10 | Кнопка «Перемешать» ставит карточки в случайный порядок. |
| F11 | Переключатель направления: какая сторона показывается первой — английская или русская. |

### Данные

| № | Требование |
|---|---|
| F12 | Пользователи, колоды и карточки хранятся в PostgreSQL и сохраняются между перезапусками. |

### Нефункциональные

- Работает на Windows 10; запускается командой `npm run dev`, открывается в браузере по адресу `http://localhost:5173`.
- Внешний вид соответствует `design/DESIGN.md`: цвета, шрифты, анимации и состав экранов.
- Интерфейс и сообщения на русском.
- Пустые случаи обработаны: нет колод, пустая колода, пустое поле при добавлении; ошибки сервера показываются понятным сообщением.
- Интерфейс пригоден для телефона: элементы перестраиваются, кнопки не меньше 44 px.
- Код разделён на слои: база данных (Prisma) → сервисы → маршруты API → интерфейс.
- Входные данные проверяются на сервере (схемы zod); ошибки API приходят в едином формате `{ "error": "текст" }`.
- Структура базы меняется только миграциями Prisma.
- Ключевые сценарии API покрыты автотестами, включая доступ к чужим данным.

## 3. Стек

| Слой | Технологии |
|---|---|
| Язык | TypeScript (сервер и интерфейс) |
| Сервер | Node.js 24 LTS + Express |
| База данных | PostgreSQL (установлен локально, служба Windows) |
| Доступ к БД | Prisma — ORM и миграции |
| Авторизация | Сессии в httpOnly-cookie (`express-session`), сессии хранятся в PostgreSQL (`connect-pg-simple`); хеш паролей — argon2 |
| Проверка данных | zod |
| Интерфейс | React + Vite + React Router; стили — CSS-модули |
| Тесты | Vitest + Supertest (API) |
| Качество кода | ESLint + Prettier |
| Запуск двух частей | npm workspaces + `concurrently` |

Точные версии пакетов фиксируются в `package.json` на этапе 1. Если argon2 не установится на Windows, допустимая замена — `bcryptjs` (только с согласия автора).

**Почему сессии, а не JWT.** Интерфейс и API работают на одном адресе (в разработке Vite проксирует `/api` на сервер), поэтому cookie передаётся автоматически. Сессию можно отозвать на сервере при выходе, а httpOnly-cookie недоступна JavaScript-коду страницы.

## 5. Модель данных

| Таблица | Поля |
|---|---|
| `users` | `id`, `email` (уникальный), `password_hash`, `created_at` |
| `decks` | `id`, `user_id` → users (каскадное удаление), `name`, `created_at`, `updated_at` |
| `cards` | `id`, `deck_id` → decks (каскадное удаление), `en`, `ru`, `created_at`, `updated_at` |
| `session` | создаётся `connect-pg-simple`: `sid`, `sess`, `expire` |

Карточки в колоде упорядочены по времени создания.

## 6. API (черновик, уточняется в плане этапа)

| Метод и адрес | Что делает |
|---|---|
| `POST /api/auth/register` | регистрация и сразу вход |
| `POST /api/auth/login` | вход |
| `POST /api/auth/logout` | выход |
| `GET /api/auth/me` | текущий пользователь или 401 |
| `GET /api/decks` | мои колоды с числом карточек |
| `POST /api/decks` | создать колоду |
| `GET /api/decks/:id` | колода с карточками |
| `PATCH /api/decks/:id` | переименовать |
| `DELETE /api/decks/:id` | удалить вместе с карточками |
| `POST /api/decks/:id/cards` | добавить карточку |
| `PATCH /api/cards/:id` | изменить карточку |
| `DELETE /api/cards/:id` | удалить карточку |
| `GET /api/health` | сервер и база доступны |

Все адреса, кроме `auth/*` и `health`, требуют входа. Чужие колоды и карточки — 404.

## 7. Этапы и приёмка

| № | Этап | Результат и проверка |
|---|---|---|
| 1 | Каркас и база | `npm install` и `npm run dev` запускают сервер и интерфейс; на `http://localhost:5173` открывается страница «Карточки». `npx prisma migrate dev` создаёт таблицы (видно в `psql`). `GET /api/health` отвечает, что база доступна. ESLint и Prettier запускаются без ошибок. |
| 2 | Авторизация | Работают A1–A3 и A5: экраны регистрации и входа, выход, после перезагрузки вход сохраняется, без входа — перенаправление на вход. В таблице `users` пароль хранится как хеш. Автотесты регистрации и входа проходят. |
| 3 | API колод и карточек | Все адреса из раздела 6 работают с учётом владельца (A4, F12). Проверка через `curl` и автотесты, включая «чужая колода → 404». |
| 4 | Экраны «Колоды» и «Колода» | Через интерфейс работают F1–F6. |
| 5 | Просмотр и доработка | Работают F7–F11; пустые состояния, сообщения об ошибках, подтверждения, вид на узком экране; пройден сценарий приёмки. |

**Сценарий приёмки:**
зарегистрироваться → создать колоду → добавить 5 карточек → изменить одну и удалить одну → пролистать с переворотом, клавиатурой и мышью → перемешать → сменить направление → перезапустить сервер и обновить страницу: всё на месте и вход сохранён → выйти и войти снова → зарегистрировать второго пользователя: колод первого не видно → вернуться к первому, удалить колоду с подтверждением.

## 8. Окружение и установка (Windows 10)

**Уже установлено:** Node.js 24, Git for Windows (терминал Git Bash), PostgreSQL (служба Windows, порт 5432), VS Code с Claude Code. Проект лежит в `C:\rufus\flashcards` (путь только латиницей и без пробелов).

**База для приложения** создаётся один раз. Открыть «SQL Shell (psql)» из меню «Пуск», войти пользователем `postgres` и выполнить (пароль задать свой):

```sql
CREATE USER flashcards WITH PASSWORD 'придумать_пароль';
CREATE DATABASE flashcards OWNER flashcards;
-- CREATEDB нужен Prisma для служебной базы при миграциях
ALTER USER flashcards CREATEDB;
```

**Полезное на Windows:**
- Остановить и запустить базу (проверка ошибок): «Службы» → `postgresql-x64-NN`, или в терминале от администратора `net stop postgresql-x64-NN` / `net start postgresql-x64-NN` (NN — версия PostgreSQL).
- `psql` из Git Bash работает, если папка `C:\Program Files\PostgreSQL\NN\bin` добавлена в PATH; иначе — «SQL Shell (psql)».
- `curl` есть в Git Bash и в Windows 10.

Далее: в папке `apps/api` скопировать `.env.example` в `.env` и вписать пароль базы и секрет сессий.

`apps/api/.env.example`:

```
DATABASE_URL="postgresql://flashcards:PASSWORD@localhost:5432/flashcards"
SESSION_SECRET="длинная_случайная_строка"
PORT=3000
```
