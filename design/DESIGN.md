# Дизайн «Карточек»

Описание макетов: цвета, шрифты, компоненты, анимации и состав каждого экрана.
Повторять нужно стиль и состав экранов; точные отступы — на усмотрение разработчика.
Экраны входа и регистрации макетов не имеют — их делаем в том же стиле (раздел 6).

Ссылки на элементы требований (F1–F12, A1–A5) — из README.

## 1. Настроение

Яркий, дружелюбный, «учебный» интерфейс: светлый сиреневатый фон, белые карточки
со скруглениями, у каждой колоды свой цвет, декоративные круги и «парящие» карточки-стикеры,
мягкие анимации. Без градиентов-заливок и эмодзи. Иконки — линейные SVG (stroke 2px).

## 2. Цвета

Задаются CSS-переменными в `:root` (файл глобальных стилей).

| Переменная | Цвет | Где |
|---|---|---|
| `--bg` | `#F4F3FB` | фон страницы |
| `--surface` | `#FFFFFF` | карточки, шапка, формы |
| `--text` | `#1B1A2E` | основной текст; тёмная оборотная сторона карточки |
| `--muted` | `#5B5A72` | вторичный текст, подписи |
| `--border` | `#E3E1F0` | рамки; `#D9D6EA` — рамки полей ввода |
| `--accent` | `#4F46E5` | основные кнопки, ссылки, фокус |
| `--accent-ink` | `#3730A3` | текст на светлом акценте, ссылки при наведении |
| `--accent-soft` | `#ECEBFF` | второстепенные кнопки, наведение на иконки |
| `--focus-ring` | `#E2E0FF` | кольцо фокуса вокруг поля (4px) |
| `--danger` | `#C2361F` | удаление, ошибки (рамка поля, кнопка «Удалить») |
| `--danger-ink` | `#B42A16` | текст ошибки |
| `--danger-soft` | `#FFF5F3` | фон поля с ошибкой, фон тоста ошибки |
| `--success` | `#17936F` | успех |
| `--success-ink` | `#0F6E52` | текст успеха |
| `--warn-soft` / `--warn-ink` | `#FFF1C9` / `#7A5400` | метка «Перемешано» |

**Цвета колод.** Каждая колода получает цвет по порядку создания (индекс по кругу из шести),
в базе цвет не хранится. Светлый — фон обложки и шапки колоды, насыщенный — декор,
тёмный — текст на светлом.

| № | Название | Светлый | Насыщенный | Тёмный текст |
|---|---|---|---|---|
| 0 | фиолетовый | `#E9E5FF` | `#6D5BD0` | `#4B3BB8` |
| 1 | голубой | `#DDEBFF` | `#2F7FD8` | `#1F5FA8` |
| 2 | мятный | `#D6F3E8` | `#17936F` | `#0F6E52` |
| 3 | коралловый | `#FFE4DA` | `#E5603D` | `#A63B1E` |
| 4 | жёлтый | `#FFF1C9` | `#C98A00` | `#7A5400` |
| 5 | розовый | `#FCE1EC` | `#D2457F` | `#9C2A5B` |

Контраст текста — не ниже 4.5:1.

## 3. Шрифты

Google Fonts:
- **Onest** (400, 500, 600, 700) — весь интерфейс.
- **Literata** (500, 600, 700) — английские слова: на карточках, в таблице, в полях ввода английского.

Размеры: заголовок страницы 48px/700 (на телефоне 32px), заголовок колоды 44px,
заголовок окна 24px/700, обычный текст 15–17px, подписи 13–14px,
надпись-метка 12px/700 капсом с разрядкой `0.12em` («ENGLISH», «ПЕРЕВОД», «КОЛОДА»).
Слово на карточке просмотра: 52px (на телефоне 40px), перевод — 44px (32px).

## 4. Компоненты

- **Шапка:** белая, нижняя рамка; слева логотип (две наложенные карточки — коралловая
  повёрнута на 10°, сверху фиолетовая с белым «Aa» шрифтом Literata) и «Карточки» 20px/700;
  справа — подпись «Английские слова, своими колодами» и меню пользователя (раздел 6).
- **Кнопки:** высота 44–52px, радиус 12–16px, шрифт 600.
  Основная — `--accent`, белый текст, мягкая тень цвета акцента.
  Второстепенная — `--accent-soft`, текст `--accent-ink`.
  Контурная — белая с рамкой `#D9D6EA`. Тёмная — `--text`, белый текст.
  Опасная — `--danger`. При наведении поднимаются на 1px, при нажатии сжимаются до 0.97.
- **Иконки-кнопки:** 44×44, прозрачные, при наведении фон `--accent-soft`, обязательно `aria-label`.
- **Поля ввода:** высота 50px, радиус 14px, рамка 1.5px `#D9D6EA`; в фокусе рамка 2px
  `--accent` и кольцо 4px `--focus-ring`; над полем `<label>` 14px/600.
  Ошибка: рамка `--danger`, фон `--danger-soft`, под полем иконка и текст `--danger-ink`.
- **Карточки-блоки:** белые, рамка `--border`, радиус 22px.
- **Модальные окна:** затемнение `rgba(27,26,46,.5)`, окно белое, радиус 24px, ширина до 480px,
  большая тень. Кнопки справа: «Отмена» (контурная) и действие (основная или опасная).
  Закрываются по Esc и по клику на затемнение; фокус переходит в окно.
- **Тосты (всплывающие сообщения):** справа снизу, ширина до 380px, радиус 16px, иконка в круге
  34px. Успех — белый с зелёной иконкой; удаление — тёмный; ошибка — `--danger-soft` с кнопкой
  «Повторить». Исчезают через 4 секунды.
- **Декор:** полупрозрачные круги насыщенного цвета колоды (opacity 0.15–0.35),
  «карточки-стикеры» с английским словом (белые, Literata) и переводом (тёмные), повёрнутые на ±5–8°,
  четырёхконечные звёздочки. Весь декор — `aria-hidden="true"`.

## 5. Анимации

Все отключаются при `prefers-reduced-motion: reduce`.

| Что | Как |
|---|---|
| Появление контента | снизу вверх на 16px с проявлением, 0.5s; карточки колод — по очереди с задержкой 0.07s |
| Наведение на карточку колоды | подъём на 5px и увеличение тени |
| Стикеры и декор | «парят» вверх-вниз на 6–12px, 4–6s, бесконечно, с разными задержками |
| Модальное окно | затемнение проявляется 0.3s, окно «выпрыгивает» из scale 0.92 с лёгким перелётом |
| Переворот карточки | 3D-поворот по оси Y, 0.65s, `perspective: 1400px`, `backface-visibility: hidden` |
| Ошибка в поле | поле трясётся по горизонтали (±6px) |
| Загрузка | скелетоны с бегущим бликом |
| Новая карточка в таблице | строка подсвечивается сиреневым и плавно гаснет |
| Конец колоды | конфетти из цветов колод падает сверху, галочка рисуется линией |
| Метка «Перемешано», индикатор прогресса | появление с пружиной; текущая точка прогресса шире остальных |

## 6. Экраны

Адреса — предложение для React Router.

### Вход `/login` и регистрация `/register` (A1–A3) — макета нет, делаем в общем стиле
По центру белая карточка шириной до 440px на фоне `--bg` с декоративными кругами и парой
«парящих» стикеров. Логотип, заголовок («Вход» / «Регистрация»), поля «Email» и «Пароль»
(у регистрации — ещё «Повторите пароль», подсказка «Не короче 8 символов»), основная кнопка
во всю ширину, ссылка «Нет аккаунта? Зарегистрироваться» / «Уже есть аккаунт? Войти».
Ошибки сервера («Неверный email или пароль», «Такой email уже зарегистрирован») — блоком
над кнопкой в стиле ошибки. Кнопка во время запроса неактивна и показывает индикатор.

### Меню пользователя (A2)
В шапке справа: круг 36px с первой буквой email (фон `--accent-soft`). По клику — выпадающий
список: email серым и пункт «Выйти». На телефоне то же самое.

### 1. Мои колоды `/` (F1–F3)
- Слева заголовок «Мои колоды», под ним «6 колод · 112 карточек», кнопка «+ Новая колода».
  Справа — иллюстрация: две парящие карточки («give up» белая, «сдаваться» тёмная),
  вращающийся пунктирный круг, звёздочка.
- Сетка карточек колод `repeat(auto-fill, minmax(300px, 1fr))`, отступ 22px.
- Карточка колоды: обложка 128px в светлом цвете колоды с кругами, стикером первого слова колоды
  и тёмной плашкой его перевода; ниже название 20px/600, число карточек, иконки «переименовать»
  и «удалить», первые 3 слова через « · » (Literata), кнопки «Листать» (основная) и «Открыть».
- Пустая колода: пунктирная рамка, «Пустая колода», текст «Добавьте карточки, чтобы начать
  листать.» и кнопка «Добавить карточки».

### 2. Первый запуск — колод нет (F2, пустой случай)
По центру: иллюстрация (три веером разложенные цветные карточки, на передней «+» и «hello»,
мерцающие звёздочки), заголовок «Пока нет ни одной колоды», текст «Создайте колоду, например
„Phrasal verbs“, и добавьте в неё слова, которые хотите запомнить.», пульсирующая кнопка
«Создать первую колоду». Ниже три шага в карточках с цветными номерами: «Создайте колоду»,
«Добавьте слова», «Листайте».

### 3. Окно «Новая колода» (F1)
Модальное окно: сверху цветная обложка будущей колоды со стикером, где показывается введённое
название, и меткой «0 карточек»; поле «Название» с подсказкой «Например: тема, учебник или
фильм»; «Отмена» и «Создать». Пустое название — ошибка «Введите название».

### 4. Колода `/decks/:id` (F4–F6)
- Ссылка «‹ Все колоды».
- Шапка колоды: блок с радиусом 26px в светлом цвете колоды и декоративными кругами;
  метка «КОЛОДА», название 44px с иконкой «переименовать», число карточек;
  справа кнопка «▶ Листать карточки».
- Форма «Новая карточка»: поля «Английский» (Literata, плейсхолдер «например, carry on»)
  и «Перевод» («например, продолжать»), тёмная кнопка «+ Добавить». После добавления фокус
  возвращается в поле «Английский».
- Таблица: «№» (номер в цветном квадратике, цвета по кругу), «АНГЛИЙСКИЙ» (Literata 17px/600),
  «ПЕРЕВОД», «ДЕЙСТВИЯ» (иконки «изменить» и «удалить»). Строка в режиме редактирования:
  оба поля прямо в строке, «Сохранить» и «Отмена»; Enter сохраняет, Esc отменяет.
  На узком экране таблица прокручивается горизонтально внутри блока.

### 5. Пустая колода и ошибка поля (F4, пустые случаи)
- Шапка колоды в её цвете, кнопка «Листать» неактивна с текстом «Листать — нужна хотя бы
  1 карточка».
- Пустое поле при добавлении — стиль ошибки, «Введите перевод» / «Введите слово», поле трясётся.
- Вместо таблицы — пунктирный блок: прыгающая стрелка вверх, две пунктирные карточки,
  «В колоде пока нет карточек», «Добавьте первую карточку через форму выше — она сразу
  появится в этом списке.»

### 6. Переименование колоды (F3)
Модальное окно: иконка-карандаш в цветном квадрате, заголовок «Переименовать колоду»,
наглядная строка «старое название (зачёркнуто) → новое название», поле «Новое название»,
подпись «31 карточка останется в колоде», «Отмена» и «Сохранить».

### 7. Просмотр `/decks/:id/study` (F7–F11)
- Шапка: «‹ Название колоды»; справа переключатель-сегменты «EN → RU | RU → EN»
  (активный — белый с тенью) и контурная кнопка «Перемешать».
- Счётчик «3 / 6» и метка «Перемешано» после перемешивания; под ним индикатор прогресса
  из точек-полосок (пройденные — светлый акцент, текущая — акцент и шире).
- Карточка 340px высотой, радиус 28px, во всю ширину колонки до 680px:
  лицевая сторона белая (метка «ENGLISH» акцентом, слово, внизу «Нажмите, чтобы перевернуть»),
  оборотная — тёмная `--text` (метка «ПЕРЕВОД» `#B9B4FF`, перевод белым,
  «Нажмите, чтобы вернуться»). Декоративные круги в углах. Вся карточка — `<button>`.
- Под карточкой: круглые кнопки ‹ и › 56px (неактивны на первой и последней) и тёмная
  кнопка-«пилюля» «Перевернуть».
- Подсказка клавиш: [Пробел] перевернуть, [←] [→] листать.
- При смене карточки она показывается лицевой стороной.
- Фон: крупные полупрозрачные парящие круги.

### 8. Конец колоды (после последней карточки — по › или →)
Конфетти, иллюстрация: стопка цветных карточек, на верхней рисуется галочка; заголовок
«Колода пролистана!», текст «Вы просмотрели все 6 карточек колоды „…“», кнопки
«Листать снова» (основная) и «Перемешать и заново» (контурная), ссылка «Ко всем колодам».

### 9. Подтверждение удаления колоды (F3)
Модальное окно: иллюстрация — веер карточек в цвете колоды с числом «×18», красный круг
с корзиной, который покачивается; заголовок «Удалить колоду „Travel“?», текст «Вместе с колодой
удалятся 18 карточек. Отменить это действие нельзя.», кнопки «Отмена» и «Удалить» (опасная)
в две колонки. Удаление карточки — без окна, с тостом «Карточка удалена».

### 10. Сообщения и ошибки сервера
- Сервер недоступен: иллюстрация с разъединённой вилкой и мигающей искрой, «Нет связи
  с сервером», «Колоды не загрузились. Проверьте, что сервер запущен, и попробуйте ещё раз.»,
  кнопка «Повторить».
- Загрузка списка колод и колоды — скелетоны в форме будущих блоков.
- Тосты: «Карточка „carry on“ добавлена», «Колода „Travel“ удалена»,
  «Не удалось сохранить. Попробуйте ещё раз» с кнопкой «Повторить».

### 11–13. Телефон (ширина 390px)
- **Колоды:** заголовок 32px; колоды списком — цветной квадрат 64px с мини-стикером (первые
  две буквы названия), название, число карточек, круглая кнопка «▶» (для пустой — «+»)
  и «⋯» (меню: переименовать, удалить); плавающая квадратная кнопка «+» справа снизу.
- **Колода:** компактная шапка «‹ Колоды» и карандаш; цветной блок колоды; форма в столбик
  (поля друг под другом, кнопка во всю ширину); список «слово / перевод» с «⋯»;
  закреплённая внизу кнопка «▶ Листать карточки».
- **Просмотр:** сегменты EN/RU во всю ширину, полоска прогресса из сегментов со счётчиком справа,
  карточка 420px высотой, «Перемешать» иконкой в шапке, внизу ‹ «Перевернуть» ›.

## 7. Доступность

- Все кнопки — `<button>`, ссылки — `<a>`, у полей — `<label>`.
- Иконки без текста — с `aria-label`; декор — `aria-hidden="true"`.
- Видимый фокус (`outline` 3px `--accent` с отступом).
- Модальные окна: `role="dialog"` (удаление — `role="alertdialog"`), `aria-modal`, Esc закрывает.
- Тосты — в контейнере `role="status"`.
- Цели касания не меньше 44×44.
